# Ponte

Ponte transforma serviços públicos dispersos em rotas claras e executáveis.

## Entrega atual

- busca por intenção e tema;
- explicação do motivo de cada recomendação;
- fontes oficiais;
- rotas conectadas;
- checklist persistido localmente;
- experiência responsiva;
- PWA e navegação offline.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Deploy

A branch `main` é a fonte de produção. O projeto é preparado para integração Git com a Vercel, de modo que cada push gere um novo deploy automaticamente.

## Limites

O Ponte organiza informação e direciona para canais oficiais. Não concede benefícios, não determina elegibilidade e não substitui o órgão responsável.
